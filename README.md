# Ayelen's Scheduler

Construí la Etapa 1 descrita en el archivo adjunto: una aplicación web funcional y deliberadamente simple para gestionar turnos de la Lic. Ayelen Pajuelo Piccoli. Implementá solamente el alcance especificado, con backend, base de datos, autenticación administrativa, reservas sin cuenta, disponibilidad/bloqueos, pagos de Mercado Pago, webhooks, cancelaciones, reprogramaciones, reembolsos, notificaciones preparadas, panel administrativo y seguridad. No trabajes el branding ni diseño visual definitivo, que será Etapa 2.
